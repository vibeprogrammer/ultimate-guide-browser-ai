# Story: "The Ultimate Guide to Browser-Based AI: Privacy-First, Offline-Ready, and Fully Future-Proof"
Speaker: Maxim Salnikov. Target 45 min (plan 42–46 min of talk + Q&A buffer). v2 (final), 16 Oct 2026. Facts come from research.md (sections cited as §n) and demo/NOTES.md. Demo URL: https://webai.isainative.dev/

## The promise (one sentence)
Every modern browser already ships enough AI plumbing to run real models on the user's device; the job in 2026 is to choose the right layer, detect what the device has, and degrade gracefully — and I'll show that live, from NPU to cloud fallback.

## The arc (7 acts)
1. Hook (3 min): a live demo first, no slides — image classification + speech-to-text running on this laptop with the network off, with the device switcher showing WASM → WebGPU → WebNN numbers. Then the title. "Everything you just saw is standard web platform or a 50 KB import."
2. Why on-device, and why now (5 min): the three trade-offs from the abstract (privacy, connectivity, cloud cost) + a fourth (latency with local media). What changed since 2023/24: GPUs became reachable (WebGPU everywhere), NPUs are in laptops and phones (WebNN), and browsers started shipping their own models (built-in AI). Hardware slide: CPU vs GPU vs NPU, kept from the old deck.
3. The landscape as a stack (12 min): one diagram used throughout, top to bottom —
   L5 Task APIs built into the browser (Translator, Language Detector, Summarizer, Writer/Rewriter, Proofreader) [R statuses]
   L4 Prompt API (LanguageModel, Gemini Nano in Chrome, Phi in Edge; multimodal; structured output) [R]
   L3 Frameworks: Transformers.js (ONNX Runtime Web), WebLLM (MLC), MediaPipe/LiteRT.js, TF.js [R]
   L2 Compute APIs: WebGPU (shipped), WebNN (coming; where it stands), WebAssembly (SIMD/threads, the universal fallback) [R]
   L1 Hardware via OS ML: Core ML / DirectML–Windows ML / LiteRT; CPU, GPU, NPU [R]
   Each layer gets a status slide ("as of Oct 2026", with source) and one code snippet that we actually ran.
4. Deep dive: WebNN × Transformers.js (8 min): what WebNN is (graph API, MLContext, device selection today) [R]; how Transformers.js routes `device: 'webnn-npu'` through ONNX Runtime Web's WebNN EP [D,R]; which models work today, which don't, and why (op coverage, dtypes); live demo 2: the switcher + benchmark table; Task Manager NPU graph moment (his signature move).
5. Deep dive: built-in AI (6 min): availability() → create() → prompt() pattern with download progress; Translator/Summarizer in 5 lines; multimodal Prompt API; Edge + Phi; what's W3C track vs vendor; live demo 3: Prompt API with fallback to Transformers.js when the API is absent.
6. Make it offline and future-proof (7 min): the decision matrix (task → layer), model sizes vs storage (Cache API / OPFS, quota, persistence) [R], Web Workers, the fallback chain built-in → WebNN → WebGPU → WASM → cloud, with feature-detection code; progressive enhancement as a product strategy; WebMCP in one slide as "the next thing": tools, not clicks, and the book.
7. Close (2 min): three takeaways, the demo link + QR, the deck link + QR, LinkedIn.

## Key facts the deck must carry (all from research.md; status slides cite their source, "as of Oct 2026")
- WebNN: W3C Candidate Recommendation (CR snapshot 22 Jan 2026, CR Draft 10 Oct 2026); WG charter targets Recommendation Q1 2027. In Chrome/Edge it is FLAG-ONLY today: about://flags/#web-machine-learning-neural-network; the Chrome origin trial was pulled 27 Mar 2026 and the Edge OT expired 11 Aug 2026 (the old deck's "origin trials to July 2026" is gone). Firefox: positive position; Safari: no position. Backends: Windows 11 24H2+ → Windows ML / ONNX Runtime (NPU + GPU; DirectML is now just one EP), macOS 14.4+ Apple Silicon → Core ML, otherwise LiteRT (CPU). Device selection: spec = powerPreference + accelerated (deviceType removed); Chromium still accepts deviceType cpu/gpu/npu; ORT Web and Transformers.js still pass deviceType. (§1)
- WebGPU: Chrome 113 (2023) on ChromeOS/macOS/Windows, Android Chrome 121, Linux Chrome 144; Firefox and Safari per §2 table (use the versions written there). Subgroups / shader-f16 per §2.
- Built-in AI in Chrome: Translator + Language Detector stable Chrome 138 (desktop only); Summarizer stable Chrome 138; Prompt API (LanguageModel) stable on the web in Chrome 148 with text+image+audio input and JSON-Schema/regex response constraints (Extensions since 138); Writer, Rewriter, Proofreader = developer trial (flag), their OTs ended. Hardware: 22 GB free disk, GPU > 4 GB VRAM or CPU 16 GB RAM + 4 cores; desktop only (Win 10/11, macOS 13+, Linux, Chromebook Plus). Pattern: availability() → create({monitor}) → prompt()/promptStreaming(). (§3)
- Edge: Prompt API dev preview (Canary/Dev since 138) on Phi-4-mini, Aion-1.0-Instruct preview from Edge 150; Writer/Rewriter dev preview; Summarizer on by default in those channels; Translator + Language Detector shipped Edge 148 (145+ languages). Same API shapes, different model → "write once, model varies" + interop concern. (§3)
- Standards: these APIs are W3C WebML Community Group deliverables (incubation), may graduate to the WG; Mozilla negative on Prompt API and Writing Assistance; WebKit opposes Prompt API. Say it honestly. (§3)
- WebMCP: WebML CG deliverable (repo active 16 Oct 2026); one slide; Maxim's book "Tools, Not Clicks" (§4 has the link if verified).
- Transformers.js 4.3.1 (6 Oct 2026): v4 = new C++ WebGPU runtime in ONNX Runtime, ~200 architectures, ModelRegistry, Tokenizers.js; devices wasm/webgpu/webnn/webnn-npu/webnn-gpu/webnn-cpu/auto; dtypes fp32/fp16/q8/int8/uint8/q4/bnb4/q4f16, default q8 on wasm else fp32; 4,272 Hub models; models cached in Cache Storage by default; 'auto' tries webnn-npu → webnn-gpu → webnn-cpu → webnn → webgpu → wasm with no hardware probing. (§5)
- Other: WebLLM 0.2.86 (WebGPU-only LLMs, ~0.9 GB for Llama-3.2-1B q4f16); ONNX Runtime Web 1.30.0; LiteRT.js 2.5.3; TF.js last release Oct 2024; Web Speech on-device (processLocally) Chrome 139; storage ≈ 60 % of disk per origin in Chromium. (§6)
- Demo (demo/NOTES.md): ResNet-50 q8 26 MB, MobileNet-v2 from the webnn org, whisper-tiny.en q8 ≈ 41 MB, SmolLM2-135M-Instruct q8 137 MB as the Prompt-API fallback; measured in headless Chrome on WASM: resnet-50 q8 186 ms avg, mobilenet-v2 fp16 76 ms, whisper-tiny.en 1.4 s, SmolLM2-135M 24 tok/s (software WebGPU slower). WebNN/NPU numbers must be measured by Maxim on his Snapdragon/Core Ultra laptop — leave a visible "measure on stage" cell.
